# GitHub Upload Checklist

Upload the contents of this `github_ready_repo` folder as the repository root.

## Include

- `README.md`
- `.gitignore`
- `analyze_radio_mobile_results.py`
- `requirements.txt`
- `DATA_AVAILABILITY.md`
- `CODEBOOK.md`
- `REPO_DETAILS.md`
- `data/baseline_radio_mobile_results.csv`
- `data/radio_mobile_expanded_results.csv`
- `data/radio_mobile_expanded_with_model.csv`
- `data/validation_metrics.csv`
- `data/validation_summary.md`
- `data/raw_radio_mobile_html/*.html`
- `figures/*.png`

## Do Not Include

- Manuscript files such as `draft_paper.tex`, `draft_paper.pdf`, and `references.bib`
- LaTeX temporary files such as `.aux`, `.bbl`, `.blg`, `.fdb_latexmk`, `.fls`, `.log`, `.synctex.gz`
- Personal names, email addresses, or affiliation details
- Prompting notes or private working drafts

## After Uploading

1. Confirm that the GitHub repository contains only data, code, figures, and documentation.
2. Add a license if your team/instructor allows it.
3. Create a GitHub release.
4. Archive the release on Zenodo if you need a DOI.
5. Replace placeholder repository or DOI links in the remaining documentation if needed.
